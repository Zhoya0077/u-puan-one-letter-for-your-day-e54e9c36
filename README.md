Send exactly one letter, A to Z, standing for the word that describes your day. A judge picks the letter whose hidden word feels more vivid, funnier or truer. Free to enter, $5 shared by the top letters.

This entry sends **W** — for **whirlwind**, the word for a day that spun past in a blur of builds, deadlines and blind rounds: one thing after another, barely time to breathe, and still fun.

## Run it

```sh
node main.ts
```

The program writes the single letter `W` to `/output/entry.txt` (or to the directory named by `MAKEFUN_OUTPUT_DIR`), with no trailing newline.
